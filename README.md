# 📈 Amazon Revenue & Profitability Forecasting

Weekly revenue and profit forecasting using SARIMA, Prophet, XGBoost and LSTM on Amazon e-commerce data.

## 🚀 Live Demo

[![Railway](https://img.shields.io/badge/Railway-Live-brightgreen)](https://amazon-revenue-forecasting-production.up.railway.app)

👉 **[amazon-revenue-forecasting-production.up.railway.app](https://amazon-revenue-forecasting-production.up.railway.app)**

## 🤖 Models Used

- **SARIMA** — Seasonal ARIMA statistical model
- **Prophet** — Facebook's time series model
- **XGBoost** — Gradient boosting with feature engineering
- **LSTM** — Deep learning recurrent neural network

## 📊 Features

- Weekly revenue & profit forecasting
- 4-model ensemble predictions
- 13-26 week future forecast
- Interactive data explorer
- Upload your own CSV data

## ☁️ Deployment

Deployed on Railway with Docker (Python 3.11)
